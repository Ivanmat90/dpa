# Contributing to DPA

First off, thanks for taking the time to contribute! ❤️

## How Can I Contribute?

### Reporting Bugs

Before creating bug reports, please check the existing issues to avoid duplicates. When you create a bug report, include as many details as possible:

- **OS and version** (`neofetch` or `fastfetch` output is perfect)
- **Steps to reproduce** (be specific)
- **Expected behavior** vs. **what actually happened**
- **Screenshots or terminal logs** (if applicable)

### Suggesting Enhancements

Have an idea to make DPA even better? Open an issue with the tag `enhancement` and describe:

- What you want to add or change
- Why it's useful
- How you think it could work

### Submitting Pull Requests

1. **Fork the repository** – you need your own copy to work on.
2. **Create a new branch** – use a descriptive name:
   ```bash
   git checkout -b feature/add-great-thing
   ```
3. **Make your changes** – code, docs, or anything else.
4. **Test your changes** – make sure nothing breaks. If you're adding code:
   - Test it manually on at least one distro (Ubuntu/Fedora/Arch).
   - Keep the code style consistent with the rest of the project.
5. **Commit and push** – write a clear commit message:
   ```bash
   git commit -m "feat: add support for opensuse zypper"
   git push origin feature/add-great-thing
   ```
6. **Open a Pull Request** – go to your fork on GitHub and click the "Compare & pull request" button. Provide a clear description of what you've done.

## Style Guidelines

- **Python**: Follow PEP 8 (but don't sweat it too much – we're all about vibecoding here).
- **Bash**: Keep it readable; use functions and avoid huge one-liners.
- **Commit messages**: Use the conventional commit style if possible (`feat:`, `fix:`, `docs:`, `chore:`).

## Philosophy

DPA started as a vibecoding project by a 15-year-old developer. The goal is to keep it **simple**, **useful**, and **friendly for beginners**. If your contribution follows these vibes, it's already halfway there.

## Code of Conduct

Be kind. DPA is a project made with love for the Linux community. Let's keep it that way.

## Questions?

Feel free to ask in the issues or discussions. We're all learning here.

**Thank you for contributing!** 🚀
